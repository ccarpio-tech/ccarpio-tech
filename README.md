## ☁️ What I'm Working On

### Carpio Travel

Carpio Travel is a website I built around my solo backpacking trip through Southeast Asia. I wanted a project where I could practice AWS and Terraform while also building something I actually cared about.

**Live Site:** [carpiotravel.com](https://carpiotravel.com)

**GitHub:** [github.com/ccarpio-tech/carpio-travel](https://github.com/ccarpio-tech/carpio-travel)

Built with:

- Terraform
- Amazon S3
- Amazon CloudFront
- Origin Access Control (OAC)
- Route 53
- AWS Certificate Manager
- IAM
- Git
- GitHub

Architecture:

`Route 53 → CloudFront + ACM → OAC → Private S3`

The site files are stored in a private S3 bucket and served through CloudFront. OAC allows CloudFront to securely access the bucket, and ACM handles HTTPS for the domain.

The AWS infrastructure is managed with Terraform.

**Next step:** GitHub Actions with AWS OIDC so deployments happen automatically when I push changes.
